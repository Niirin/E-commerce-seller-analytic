# E-commerce Seller Performance Analytics

An end-to-end analytics project exploring how small e-commerce sellers can monitor performance, identify underperforming products, and make better sales decisions.

## Project structure

- `data/` — source and processed datasets
- `sql/` — queries and data preparation scripts
- `notebooks/` — exploratory analysis and modeling
- `powerbi/` — Power BI reports and dashboard files
- `documentation/` — project notes, metric definitions, and decisions
- `images/` — dashboard screenshots and supporting visuals
